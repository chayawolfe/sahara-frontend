# Sahara Frontend

A modern frontend for a sports betting and online casino platform, designed to deliver a premium user experience for sportsbook browsing, live betting, casino games, account management, promotions, and secure wallet interactions.

This project is built with React and follows a clean, scalable component-based structure to support a responsive and high-converting betting experience.



## Design Reference

- Figma Design: https://www.figma.com/design/j0NZdHaQC9iHOuFKS9ltfS/Desktop-version--Copy-?node-id=0-1&p=f&t=azIG0SeYOoEfbGCS-0

## Overview

Sahara Frontend is a digital betting platform interface focused on:

- Sports betting UI with event listings and odds
- Live casino and slot game presentation
- User authentication and account management
- Wallet and transaction flows
- Promotions, bonuses, and loyalty features
- Responsive layout for desktop and mobile screens
- Fast, modern experience built with React and MUI

## Key Features

- Sportsbook dashboard with match cards and betting markets
- Casino section highlighting games and offers
- Promotional banners and campaign sections
- User profile, dashboard, and transaction history screens
- Wallet and deposit/withdraw flow UI
- Localization-ready architecture for multiple languages
- Theme-based styling and reusable UI components
- Modular route and page structure for future expansion

## Tech Stack

- React 18
- TypeScript
- React Router
- Material UI (MUI)
- Axios for API integration
- i18next for internationalization
- SCSS / custom CSS styling
- Vite / CRA-based setup (depending on project structure)

## Prerequisites

- Node.js 16.x or 18.x
- npm or yarn

## Installation

### Using Yarn (Recommended)

```bash
yarn install
yarn start
```

### Using npm

```bash
npm install
# or
npm install --legacy-peer-deps
npm start
```

## Production Build

```bash
npm run build
```

## Notes

This repository is the frontend layer of a betting platform and is intended to be connected to backend APIs for real-time odds, authentication, wallet actions, and transaction processing.
